## 配置 dev server 支持局域网 IP 访问
- 修改 `vite.config.ts`：`server` 增加 `host: true`、`strictPort: true`、`allowedHosts: true`；同时为 `preview` 增加相同配置。
- 原因：默认只监听 localhost；且 Vite 6 的 host 检查会拦截以 IP 作为 Host 头的请求（返回 Blocked request）。
- 本机局域网 IP 为 10.11.12.47，端口 2025，已验证 `curl http://10.11.12.47:2025/` 返回 200。
- 启动命令：`npm run dev`（predev 会先执行 scripts/build-viewer.mjs 生成 public/export-runtime.js）。
